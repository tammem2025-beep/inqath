# حديقة الأصدقاء (inqath)

لعبة جوال هادئة للأطفال: ازرع الزهور، والعب مع الحيوانات، وخذ نَفَساً عميقاً متى شئت.

- لا خسارة ولا نقاط ولا مؤقتات.
- لا أصوات مفاجئة؛ الصوت مغلق في البداية ويُفتح من زر 🔊.
- ركن تنفّس هادئ (زر 🎈): بالون يكبر ويصغر ببطء.
- لا تجمع أي بيانات، وتعمل بدون إنترنت بعد أول فتح.

## تشغيلها على الجوال

1. فعّل GitHub Pages: من صفحة المستودع افتح **Settings** ثم **Pages**، واختر **Deploy from a branch**، ثم الفرع **main** والمجلد **/ (root)**، واضغط **Save**.
2. بعد دقيقة أو دقيقتين يصبح الرابط: `https://tammem2025-beep.github.io/inqath/`
3. افتح الرابط على الجوال:
   - **أندرويد (Chrome):** قائمة ⋮ ثم **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
   - **آيفون (Safari):** زر المشاركة ثم **إضافة إلى الشاشة الرئيسية**.
4. ستظهر أيقونة اللعبة على الشاشة الرئيسية، وتُفتح بملء الشاشة كأي تطبيق.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | اللعبة كاملة |
| `manifest.webmanifest` | بيانات التثبيت (الاسم والأيقونة والألوان) |
| `sw.js` | يجعلها تعمل بدون إنترنت |
| `icon-*.png` | أيقونات التطبيق |

> هذه تطبيق ويب قابل للتثبيت (PWA)، وليست ملف APK. إن أردت نشرها في متجر Google Play أو App Store يمكن تغليفها لاحقاً بأدوات مثل PWABuilder أو Capacitor.
